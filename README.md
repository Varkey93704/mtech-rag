# AI-Augmented Test Automation Framework

## M.Tech Dissertation Project

AI-Augmented Test Automation Framework using RAG, DeepEval, and CI/CD.

## Project Status

Initial development — RAG baseline setup.

## Baseline RAG Configuration

- Language: Python
- LLM Runtime: Ollama
- Generation Model: Llama 3.1
- LLM Framework: LangChain
- Vector Store: ChromaDB
- Embedding Model: all-MiniLM-L6-v2
- Chunk Size: 512 tokens
- Top-K: 5

## Research Objective

The project investigates how retrieval configuration and evaluation techniques can improve the reliability of LLM-powered applications.
